SMART FEATURES

More than a blood request form.

LifeLink combines emergency communication, donor matching, and hospital coordination into one concept.

⌁

Smart donor matching

This demo matches the exact blood group and donors marked available now or today. It does not calculate distance, eligibility, or response history.

↗

Smart Donor Relay

Starts with a small nearby donor radius and expands only when enough responses are not received.

▣

Emergency QR profile

A future QR profile can show essential emergency details after verified access and consent.

◉

Hospital command view

Hospitals can track open requests, donor responses, verification status, and request urgency.

◌

Live request timeline

Families can understand whether a request is created, verified, matched, or fulfilled.

⌘

Multilingual support

Emergency instructions can be presented in simple language to improve accessibility.

ABOUT THIS PROJECT

A prototype for emergency coordination.

LifeLink is currently a front-end demonstration. Requests and donor registrations are stored in this browser only. The project does not verify hospitals or donors, send notifications, or guarantee blood availability. For an actual emergency, contact a hospital or licensed blood bank.
